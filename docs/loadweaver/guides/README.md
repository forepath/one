# Guides

End-to-end walkthroughs that combine several Loadweaver features.

- [Agenstra on Loadweaver](./agenstra-on-loadweaver.md) Agenstra's agent manager as a Loadweaver deployment, environments as sandboxed deployments with egress compiled from Agenstra's policy, or on the node's Docker as delegated containers
- [Terraform](./terraform.md) The `forepath/loadweaver` provider: dry-run Loadweaver plans on `terraform plan`, applied plans (with approvals) on `terraform apply`, resources, data sources and import
