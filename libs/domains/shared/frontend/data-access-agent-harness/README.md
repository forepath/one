# data-access-agent-harness

Angular data access for agent chats built on the [agent harness](../../shared/util-agent-harness/README.md): NgRx state (`agentHarness` feature), a facade, and a transport that talks either to the application's own relay endpoints (recommended; see `feature-agent-harness`) or directly to an Agenstra agent's OpenAI-compatible API with browser tools.

See `docs/agenstra/features/agent-harness.md`.
