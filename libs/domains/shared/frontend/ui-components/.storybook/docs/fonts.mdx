# Fonts

Consoles use **Plus Jakarta Sans Variable** as `$font-family-base`, with **`$font-size-base: 0.875rem`** (14px) so dense billing/agent UIs stay compact. Icons come from **Bootstrap Icons**.

## Loading

Apps (and Storybook) load:

```scss
@import '@fontsource-variable/plus-jakarta-sans/wght.css';
@import 'bootstrap-icons/font/bootstrap-icons';
```

Bootstrap then exposes `--bs-body-font-family` / `--bs-body-font-size` from the Sass overrides.
