# FPC component catalog

Selector prefix: **`fpc`** (ForePath Component). Import from `@forepath/shared/frontend/ui-components`.

All components are standalone. Prefer CSS variables (`--bs-*`) for color. See Storybook for inputs/outputs.

| Selector                       | Notes                                                                                                                                                                                                                                                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fpc-button`                   | Variants, sizes (`xs`–`xl`; `xl` = landing CTA), loading; `iconOnly` (1:1); optional `href` / `btnClass` / `dataBsDismiss`. Prefer solid variants in consoles; `outline-*` reserved for landing. `size="xl"` auto-tones: darkened primary in `#cta`/`#fit`, soft dark in `#hero` (`--fpc-btn-hero-dark-*`). |
| `fpc-button-group`             | Related `fpc-button` cluster with a slight gap (`size` sm/md/lg sets default gap; optional `gap` override). Not a flush Bootstrap `btn-group`.                                                                                                                                                              |
| `fpc-badge`                    | Solid Bootstrap badge, console info chip (`variant="info"`; `size="sm"` matches `btn-sm`), or landing soft chip (`variant="marketing"`; `size="xl"` for hero feature rows)                                                                                                                                  |
| `fpc-status-badge`             | Circular icon well                                                                                                                                                                                                                                                                                          |
| `fpc-avatar`                   | Image or initials                                                                                                                                                                                                                                                                                           |
| `fpc-icon`                     | Bootstrap Icons (`name` without `bi-`)                                                                                                                                                                                                                                                                      |
| `fpc-label`                    | Form label                                                                                                                                                                                                                                                                                                  |
| `fpc-form-control`             | Input / select / textarea (+ CVA); sizes `sm`–`xl`; `min`/`max`/`step`/`pattern`/`maxLength`; `controlClass`; `multiple` + `htmlSize` for multi-select; `filesChange` for `inputType="file"`; host is flex item inside `input-group`                                                                        |
| `fpc-form-field`               | Label + control + hint/error                                                                                                                                                                                                                                                                                |
| `fpc-form-check`               | Checkbox / radio (`type`); CVA boolean for checkbox; `valueSelect` for radio                                                                                                                                                                                                                                |
| `fpc-form-check-group`         | Fieldset-like group for related checks (`label`, `inline`, `hint`)                                                                                                                                                                                                                                          |
| `fpc-form-switch`              | Switch                                                                                                                                                                                                                                                                                                      |
| `fpc-input-group`              | Prefix/suffix slots                                                                                                                                                                                                                                                                                         |
| `fpc-search-field`             | Console search strip (`appearance="default"`) or landing/blog hero search (`appearance="marketing"` + `size="xl"`); CVA; clear overlays so the × does not widen the field                                                                                                                                   |
| `fpc-typeahead-select`         | Typeahead chrome; `variant="menu"` (default) fixed + body-portaled dropdown, or `variant="inline"`; clear overlays (stable width); hides results host while `loading`                                                                                                                                       |
| `fpc-otp-input`                | 6-char OTP CVA (migrated from identity)                                                                                                                                                                                                                                                                     |
| `fpc-tab`                      | Single segmented tab                                                                                                                                                                                                                                                                                        |
| `fpc-tab-group`                | Tab host (`role=tablist`); equal-width segmented buttons                                                                                                                                                                                                                                                    |
| `fpc-dropdown`                 | Dropdown host (`direction` down/up)                                                                                                                                                                                                                                                                         |
| `fpc-dropdown-item`            | Menu row (action, `routerLink`, or `href`; optional end actions via `fpcDropdownItemEnd`)                                                                                                                                                                                                                   |
| `fpc-tooltip`                  | Hover/focus tip; preferred `placement` flips in the clip/scroll ancestor; fixed + body-portaled bubble (`appearance` default/panel)                                                                                                                                                                         |
| `fpc-accordion`                | Accordion host                                                                                                                                                                                                                                                                                              |
| `fpc-accordion-item`           | Accordion section                                                                                                                                                                                                                                                                                           |
| `fpc-list`                     | List host; flush keeps last-row bottom border                                                                                                                                                                                                                                                               |
| `fpc-list-item`                | List row (title/meta/actions slots)                                                                                                                                                                                                                                                                         |
| `fpc-list-search`              | Search + list layout                                                                                                                                                                                                                                                                                        |
| `fpc-list-append-footer`       | Infinite-scroll footer                                                                                                                                                                                                                                                                                      |
| `fpcInfiniteScroll`            | Infinite-scroll directive                                                                                                                                                                                                                                                                                   |
| `fpc-section-container`        | Page shell                                                                                                                                                                                                                                                                                                  |
| `fpc-section-row`              | Page row (`marketingHidden`, `nowrap`)                                                                                                                                                                                                                                                                      |
| `fpc-section-column`           | Page column (`scroll`, `variant`: default/marketing/form, optional `title`)                                                                                                                                                                                                                                 |
| `fpc-board-lane`               | Lane inside a column (`scrollBody`, `listGroup`, `exportAs: fpcBoardLane` → `scrollRoot`)                                                                                                                                                                                                                   |
| `fpc-lane-header`              | Card / lane subheader (`py-2 small fw-semibold`); `visibility` always/md-up                                                                                                                                                                                                                                 |
| `fpc-summary-bar`              | Metrics strip; completed rows get full-width bottom dividers; incomplete last-row cards keep a right edge                                                                                                                                                                                                   |
| `fpc-summary-card`             | Metric cell (label / value / actions); value via `[fpcSummaryCardValue]`; actions via `[fpcSummaryCardActions]` (wrapped in `fpc-button-group`)                                                                                                                                                             |
| `fpc-pagination`               | Pagination                                                                                                                                                                                                                                                                                                  |
| `fpc-breadcrumbs`              | Breadcrumb host                                                                                                                                                                                                                                                                                             |
| `fpc-breadcrumb-item`          | Crumb                                                                                                                                                                                                                                                                                                       |
| `fpc-toast-container`          | Toast stack                                                                                                                                                                                                                                                                                                 |
| `fpc-toast`                    | Toast                                                                                                                                                                                                                                                                                                       |
| `fpc-modal`                    | Modal shell; `accent` primary/danger/warning for corner close; footer via `*fpcModalFooter`                                                                                                                                                                                                                 |
| `fpc-confirm-dialog`           | Confirm dialog; `danger` / `warning` set confirm button + close accent                                                                                                                                                                                                                                      |
| `fpc-alert`                    | Alert (`showIcon` default on; `flush` for full-width under page headers; trailing CTAs via `[fpcAlertActions]`)                                                                                                                                                                                             |
| `fpc-empty-state`              | Empty list/board; stretch in flex columns. Collection empty: default `hourglass-split` + domain copy. Active search with zero hits: `icon="search"` + message **No search results**                                                                                                                         |
| `fpc-spinner`                  | Spinner                                                                                                                                                                                                                                                                                                     |
| `fpc-loading-overlay`          | Fullscreen overlay                                                                                                                                                                                                                                                                                          |
| `fpc-progress`                 | Progress                                                                                                                                                                                                                                                                                                    |
| `fpc-page-header`              | Console title strip (`bg-body-tertiary`); `density` default/compact; stable height with/without actions                                                                                                                                                                                                     |
| `fpc-top-bar`                  | Dark top bar (brand + actions); `compact` for no-brand strip; meta chips use `fpc-top-bar__chip`; icon/link actions use `fpc-top-bar__action` (fixed light chrome); actions tighten below `md`                                                                                                              |
| `fpc-sidebar`                  | Sidebar rail; items scroll, `[fpcSidebarFooter]` stays pinned                                                                                                                                                                                                                                               |
| `fpc-sidebar-nav-item`         | Sidebar tile                                                                                                                                                                                                                                                                                                |
| `fpc-sidebar-popover`          | Admin tile grid                                                                                                                                                                                                                                                                                             |
| `fpc-language-switcher`        | Locale dropdown: `appearance="default"` (icon + code) or `footer` (soft dark chip + Language label + dropup; `--fpc-lang-footer-btn-*`); optional locale `href`s                                                                                                                                            |
| `fpc-theme-switcher`           | Dark / light toggle                                                                                                                                                                                                                                                                                         |
| `fpc-collapsible-filter-panel` | Collapsible filters                                                                                                                                                                                                                                                                                         |
| `fpc-notification-indicator`   | Attention dots                                                                                                                                                                                                                                                                                              |

Global SCSS (load once after Bootstrap in app `styles.scss`): `styles/index.scss` — scrollbar only. Modal / icon-button / sidebar-popover chrome ship with their components. Do not reintroduce copies under `libs/domains/shared/frontend/*.scss`.
