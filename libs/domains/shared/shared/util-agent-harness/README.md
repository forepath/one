# util-agent-harness

Framework-agnostic (Node 18+ and browsers) mini-harness for one Agenstra agent's [OpenAI-compatible API](../../../../../docs/agenstra/features/openai-compatible-api.md): typed client (models, chat completions, responses, conversations), SSE reader, function tool registry with argument guards and approval, context providers, sessions and the client tool loop.

See `docs/agenstra/features/agent-harness.md`. NestJS: `@forepath/shared/backend/feature-agent-harness`; Angular: `@forepath/shared/frontend/data-access-agent-harness`.
