# loadweaver-frontend-feature-landingpage

Pages, layout, routes and content of the Loadweaver landing page (`loadweaver.com`, app `loadweaver-frontend-landingpage`, port 4600): home, how it works, apps, remote access, cloud, pricing, comparisons and legal pages. The site is pre-launch: every call to action leads to the shared contact form with an early access prefill.

Source-available (viewing only), see [LICENSE](./LICENSE).

## Running unit tests

Run `nx test loadweaver-frontend-feature-landingpage` to execute the unit tests.
