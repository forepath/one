Loadweaver Desktop

The console as a native app, with the fleet view, OS notifications for alerts, and terminals and tunnels one click away. It runs your VPN tunnel too.

OS-native WireGuard

Kernel WireGuard on Linux, wireguard-nt on Windows and WireGuardKit in a Network Extension on macOS. No own crypto.

Enrollment and posture

Enrollment, key renewal after sign-in and posture reports, plus a view of the services you may reach.

Code-signed

Apple Developer ID with notarization, Windows Authenticode, and signed apt and rpm repositories on Linux, with checksums on top.

Verified updates

In-app updates on stable and beta channels, verified by signature and manifest before install, and never silently downgraded.

Loadweaver for phones and tablets

The console in a mobile layout: the overview and the needs-attention inbox, alerts as push notifications, approvals on the go, logs and the map.

Available in the App Store and Google Play, and through managed distribution with Intune, Jamf or Kandji.

Alerts and approvals

Push notifications when something needs attention, and approvals for plans wherever you are.

A tunnel in your pocket

WireGuardKit in a Packet Tunnel extension on iOS and the official wireguard-android library on Android.

Posture you can trust

Passcode or biometrics, OS patch level, jailbreak and root detection, and app attestation so reports cannot be faked by a modified app.

A CLI for people, an MCP server for agents

Both work against the same API as the console, with the same access rules, approvals and audit trail.

Loadweaver CLI

Single binaries for Linux, macOS and Windows on amd64 and arm64. Published on npm, GitHub releases, an install script, Homebrew, a deb / rpm repository and as a container image, signed with cosign and checksums.

MCP server

loadweaver mcp in the CLI for local agents, and a remote MCP endpoint for hosted agents, including Agenstra's. Agents can read state, query logs and metrics, create plans and request approvals, but never bypass them.
